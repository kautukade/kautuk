# GorBaano E-commerce Prototype

This repository contains a simple static prototype for **GorBaano**, a ladies' garments store. The site demonstrates the user flows for both the public shopping experience and the admin panel.

## Public Panel
- Responsive navbar on all pages with links to shop, categories, about, contact, track order, login/register and cart
- Product listing and detail pages with add-to-cart functionality
- Cart management and basic checkout form
- Order confirmation and profile placeholder
- Additional pages: categories, about, contact, track order

## Admin Panel
- Admin login screen
- Dashboard with placeholder stats
- Management pages for products, orders and customers

This code uses **Bootstrap 5** and simple JavaScript with local storage for the cart. It is intended as a design and flow mock-up only.
